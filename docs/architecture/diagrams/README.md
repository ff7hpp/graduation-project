# Architecture diagrams

Prepare editable Mermaid (`.mmd`), PlantUML (`.puml`), Structurizr DSL (`.dsl`), Draw.io (`.drawio`), Excalidraw (`.excalidraw`), or DBML (`.dbml`) sources when appropriate. Prefer SVG exports when a renderer is available. Use [`evidence-inventory.md`](evidence-inventory.md) before diagramming, link each diagram from the architecture document, and state its scope and status. No fictional diagrams are included.

Candidate diagrams are the system context, component, sequence, entity relationship, and deployment diagrams. Choose notation by purpose and validate syntax and rendered layout when tools permit.
